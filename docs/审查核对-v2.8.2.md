# BioAssay Studio 审查意见核对（2026-07-26）

核对对象：`BioAssay_Studio_审查报告_20260725.md`  
当前源码目标版本：v2.8.2

## 结论

原报告的算法链路梳理和主要技术债判断总体有价值，但它是“只做静态分析、未运行 GUI”的 v2.8.1 快照，部分结论过度概括，部分内容已在 v2.8.2 修复。不能直接把报告中的参数建议全部应用到 WB 自动识别：统一提高灵敏度或放宽边界会同时增加假阳性，必须用有人工真值框的多类样图做精确率、召回率和边界 IoU 回归后再改默认值。

## 报告其他模块核对

### qPCR

- 内参自动匹配确实包含 `GAPDH / ACTB / ACTIN / 18S / RPLP0 / UBQ5`，不包含 `eEF-1α` 的常见写法；用户仍可手动选择内参，因此不是计算错误。后续可补充别名，但不能把自动猜测当最终实验设计。
- 结果表已经显示效率校正结果，CSV 已导出每个基因的 primer efficiency；报告所说“UI 不显示当前效率”不完全准确，因为配置步骤有逐基因效率输入。可以在结果摘要再显示一行所用效率，提升可追溯性。

### 考马斯亮蓝

- 线性回归、重复 SD/CV、空白扣除、原液浓度和 mg/g 公式核对正确。
- 报告指出核心函数允许 0 倍稀释是对的；界面下拉原本已限制 1–100×，v2.8.2 又把核心函数的下限修正为 1，避免外部调用或旧数据产生无物理意义的 0 倍。

### 实验知识库

- IndexedDB、独立自动保存队列、附件延迟读取、备份事务设计评价成立。
- 报告称 `seedChemicals()` 只在空库写入“逻辑正确”，但这会导致旧用户升级后拿不到新增试剂。v2.8.2 改为只补充缺失的内置试剂，不覆盖用户修改记录。
- 中文搜索不是专业分词器，但当前 `includes` 对连续中文子串有效；空白分词采用 AND 逻辑。以后可加字段权重和拼音/别名，不应在完全离线版本中贸然引入大型分词依赖。
- v2.8.2 重整知识库空白页与编辑页列布局；计算结果在宽度不足时转到表单下方，不再缩成被遮挡的窄栏。
- 多组分 Buffer 现在可按名称/别名检索 47 种常用试剂和明确水合物，精确匹配后自动填入分子量。混合物（Triton X-100、Tween 20）明确提示无固定分子量，应按百分体积配制。

### 图表与导出

- `figureFramePlacement` 和 PNG pHYs DPI 元数据实现评价成立。
- SVG 中条带图像是光栅嵌入，这是保存原始实验图像真实性所必需；不能把真实条带伪造成矢量矩形。文字和框线可以保持矢量，这是合理边界。

## 本次 v2.8.2 已完成

1. 知识库桌面三栏和计算器结果区重排，解决窄栏遮挡与显示不完整。
2. 内置试剂库扩充到 47 项，支持中英文名称、别名、化学式和水合物精确匹配；旧数据库升级会补充缺失试剂。
3. 多组分 Buffer 名称输入自动回填分子量，并显示匹配来源或“混合物无固定分子量”提示。
4. 真正的中英文离线 OCR，带进度、置信度和人工校对提醒。
5. 截图可直接创建实验方法，也可附加到已有方法并在编辑区预览。
6. 考马斯核心稀释倍数下限修正为 1。
7. 新增分析核心、配方核心和 OCR 离线资源集成测试。
